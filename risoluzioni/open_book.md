# Esempio di risoluzione — Metodo di studio open book

## Obiettivo
Spiegare come usare i file di `Parte A` durante l’esame.

## Procedura consigliata
1. Cerca la parola chiave del tema: `subnet`, `routing`, `TCP`, `throughput`, `NAT`, `ARP`.
2. Apri una traccia simile già svolta.
3. Copia lo schema di soluzione, non i numeri.
4. Adatta i dati del nuovo esercizio.
5. Scrivi in modo ordinato: **Dati → Ipotesi → Procedura → Risultato**.

## Regole pratiche
- Non partire mai dal file “più recente”: parti dal tema.
- Tieni pronto un mini-formulario con prefissi, potenze di 2, unità di misura e formule base.
- Se l’esercizio è ambiguo, dichiara le ipotesi in modo esplicito.

## Errori comuni
- Cercare una soluzione identica invece di una traccia analoga.
- Saltare la fase di lettura dei vincoli.
- Confondere lo studio del file con la risoluzione del nuovo testo d’esame.

## Checklist finale
- [ ] Ho riconosciuto il tema principale?
- [ ] Ho recuperato la traccia modello giusta?
- [ ] Ho verificato unità, prefissi e ipotesi?
- [ ] Ho scritto il risultato finale in modo chiaro?
