# Esempio avanzato di risoluzione — Metodo open book

## Obiettivo
Usare in modo efficiente la cartella `Parte A` durante l’esame.

## Strategia di consultazione
### 1. Riconosci il tema
Leggi subito il testo e individua la famiglia dell’esercizio:
- subnetting/VLSM
- routing
- TCP/UDP
- prestazioni
- NAT/ARP/servizi

### 2. Recupera una traccia gemella
Cerca un file con lo stesso tipo di esercizio e confronta:
- schema
- formule
- ordine dei passaggi
- tipo di risposta richiesta

### 3. Usa un template fisso
Per ogni esercizio scrivi sempre:
- **Dati**
- **Ipotesi**
- **Procedura**
- **Risultato**

### 4. Verifica le unità
Prima di calcolare controlla:
- bit/byte
- Mbps/MB/s
- ms/s
- prefissi IPv4

### 5. Chiudi con un controllo di coerenza
Chiediti:
- il risultato sta nel range corretto?
- il prefisso è compatibile con il numero di host?
- la rotta scelta è davvero la più specifica?
- il throughput è coerente con il link più lento?

## Errori tipici da evitare
- Cercare la soluzione esatta invece del pattern di soluzione.
- Partire dai file in ordine cronologico.
- Saltare i passaggi intermedi per “fare prima”.
- Non dichiarare le ipotesi quando il testo è ambiguo.

## Checklist finale
- [ ] Ho riconosciuto il tema?
- [ ] Ho trovato un file simile?
- [ ] Ho adattato la procedura al testo nuovo?
- [ ] Ho controllato unità e prefissi?
- [ ] Ho scritto una risposta chiara e completa?
